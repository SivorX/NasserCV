# Nasser Abukhalil - Portfolio

A responsive personal portfolio website built with HTML, CSS, and vanilla JavaScript.


## Deploy with GitHub Pages

1. Push the project files to a GitHub repository, keeping `index.html` at the repository root.
2. In the repository, open **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)` folder, then click **Save**.
5. After GitHub Pages finishes deploying, open the URL shown in the Pages settings.

## Project files

- `index.html` - page content and section structure
- `styles-clean.css` - active stylesheet linked by `index.html`
- `styles.css` - older stylesheet; it is not currently loaded by the page
- `script.js` - mobile navigation and scroll-reveal behavior
- `profile-photo.jpg` - portrait displayed in the hero section

## Site sections

- About
- Education, with high school before university
- Skills and courses
- Contact links

The site also includes a continuously scrolling interests banner, responsive layouts, and reduced-motion support.
